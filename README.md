# Expense Tracker

A Python-based expense tracking application with GUI and analytics.

## Features
- Add, view, and delete expenses
- Categorize expenses (Food, Transport, etc.)
- Visual analytics with charts
- Monthly and category-based summaries
- CSV data storage
